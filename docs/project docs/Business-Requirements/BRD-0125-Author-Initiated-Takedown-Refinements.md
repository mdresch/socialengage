# BRD-0125: Author-Initiated Takedown Refinements

**Status:** Proposed (2026-08-28)
**Source:** ADR-0125

## Requirements
- BR-125.1 45-day default response SLA clock on verified DSRs.
- BR-125.2 Bot protection (CAPTCHA) on public submission forms.
- BR-125.3 Advisory-only AI risk-flagging for human reviewers.
- BR-125.4 Complete redaction cascade into AI enrichment tables.

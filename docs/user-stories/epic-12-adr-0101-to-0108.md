## Story 12.1 — Connector capability matrix (backend)

**Source:** ADR-0101 · **Status:** Ready
**Built:** yes (2026-08-29)

**As a** backend engineer,
**I want** `SocialConnector.getCapabilities()` and `GET /v1/connectors/capabilities`,
**so that** the admin UI and composer can discover what each platform supports.

**Acceptance Criteria**
- `SocialConnector` returns `poll`, `count`, `publish`, `reply`, and `backfill` capabilities.
- Capabilities can vary by connector implementation and tenant API tier.
- `GET /v1/connectors/capabilities` returns all registered connectors with their capabilities.
- `GET /v1/connectors/:platformId/health` combines `ConnectorHealth` and capabilities.
- At least three existing connectors return realistic capability objects.

## Story 12.3 — Boolean query AST and visual builder (backend)

**Source:** ADR-0102 · **Status:** Ready
**Built:** 2026-08-29 (contract `contracts/epic-12/story-12.3.boolean-query-ast.contract.test.ts`)

**As a** backend engineer,
**I want** a canonical `WatchlistAST`, `GET /v1/connectors/:platformId/query-capabilities`, and save-time validation,
**so that** watchlist queries are visual, platform-aware, and fail fast.

**Acceptance Criteria**
- `WatchlistAST` schema supports `keyword`, `phrase`, `hashtag`, `mention`, `author`, `source`, `sentiment`, `date`, and `nested` clauses.
- `watchlists` table uses `ast` as the canonical field; `boolean_query` text is migrated or deprecated.
- Each connector exposes `supportedClauses`, `supportedOperators`, and limits.
- Save-time validation returns `422 UNSUPPORTED_QUERY_CLAUSE` with the offending clause.
- Fallback matching continues to evaluate the AST in process.

## Story 12.11 — Public API versioning and webhooks (backend)

**Source:** ADR-0106 · **Status:** Complete
**Built:** Yes — contracts/epic-12/story-12.11.public-api-and-webhooks.contract.test.ts (10/10 pass)

**As a** backend engineer,
**I want** rate-limited public API access and HMAC-signed webhook delivery from Service Bus events,
**so that** tenants can integrate with the platform.

**Acceptance Criteria**
- Public endpoints under `/v1/` are reachable with Entra bearer tokens.
- Rate limiting returns `X-RateLimit-*` headers.
- `POST /v1/webhooks/subscriptions`, `GET/PATCH/DELETE` endpoints exist.
- `WebhookDeliveryWorker` signs payloads with `HMAC-SHA256(secret, body)` and retries with backoff.
- Failed deliveries are dead-lettered after 10 attempts.

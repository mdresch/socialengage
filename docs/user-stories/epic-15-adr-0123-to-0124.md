## Story 15.2 — Data export lookback bounding and representative sampling (backend)

**Source:** ADR-0124 (Accepted 2026-08-28) · **Status:** Ready  
**Built:** 2026-09-07 — social-listening-core@2f905ff  
*(Relates to Story 10.8 — see epic-10 for the currently-shipped version this would revise)*

**As a** Tenant-User,  
**I want** to request representative sampled CSV exports and have date ranges safely validated,  
**so that** I can instantly inspect high-volume trends without triggering server timeouts.

**Acceptance Criteria**
- GET /v1/posts/export.csv rejects ranges exceeding 24 months with 400 EXPORT_RANGE_TOO_LARGE.
- sample=true query returns deterministic representative row sample and sets X-SocialEngage-Sampled: true.

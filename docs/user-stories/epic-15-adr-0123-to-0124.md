# Epic 15: Research-driven ADR revisions — Alerts and Export (ADRs 0123–0124)

## Story 15.1 — Real-time alert rule exclusions, caps, and pre-save volume preview (backend)

**Source:** ADR-0123 (Proposed 2026-08-28) · **Status:** Ready  
**Built:** not yet  
*(Relates to Story 10.9 — see epic-10 for the currently-shipped version this would revise)*

**As a** Tenant-Admin,  
**I want** to configure noise exclusions, daily caps, and preview alert firing volume before saving rules,  
**so that** our team is not overwhelmed by alert fatigue.

**Acceptance Criteria**
- lert_rules schema supports excluded_watchlist_ids, excluded_topic_ids, and max_alerts_per_day.
- AlertEvaluationWorker respects exclusion lists and suppresses firing when daily cap is reached.
- POST /v1/alert-rules/preview returns estimated alert counts over the specified lookback window.

## Story 15.2 — Data export lookback bounding and representative sampling (backend)

**Source:** ADR-0124 (Proposed 2026-08-28) · **Status:** Ready  
**Built:** not yet  
*(Relates to Story 10.8 — see epic-10 for the currently-shipped version this would revise)*

**As a** Tenant-User,  
**I want** to request representative sampled CSV exports and have date ranges safely validated,  
**so that** I can instantly inspect high-volume trends without triggering server timeouts.

**Acceptance Criteria**
- GET /v1/posts/export.csv rejects ranges exceeding 24 months with 400 EXPORT_RANGE_TOO_LARGE.
- sample=true query returns deterministic representative row sample and sets X-SocialEngage-Sampled: true.
